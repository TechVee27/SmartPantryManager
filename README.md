# Smart Pantry Manager

A Java Android application for tracking ingredients already at home and suggesting recipes only when every required ingredient is available in sufficient quantity. Built for Mobile App Development 700.

## Features
- Five Activities: pantry, add/edit ingredient, suggested recipes, recipe detail and settings.
- SQLite pantry CRUD with persistence between app sessions.
- Custom ListView adapter and refresh in onResume.
- Twenty recipes seeded into SQLite, with ingredient quantities and preparation steps.
- Strict matching, common singular/plural aliases, combined stock, kg/g and compatible volume conversion.
- Saved preference for expiry-date ordering, confirmation before deletion and form validation.
- Toolbar navigation menu and explicit Intents carrying record IDs.

## Database choice
SQLiteOpenHelper provides offline, on-device storage without accounts, servers or connectivity. It is suitable for this single-user pantry and demonstrates SQL tables, foreign keys, queries and CRUD directly. SharedPreferences stores the expiry-sort preference.

Tables: pantry_items(id, name, quantity, unit, expiry_date); recipes(id, name, method); recipe_ingredients(id, recipe_id, name, quantity, unit). recipe_id references recipes.id. Version 2 seeds recipes on upgrade without removing pantry data.

## Setup and run
1. Clone this repository and open its root folder in Android Studio.
2. Install the Android SDK platform requested by app/build.gradle.kts (compile/target API 37); minimum Android API 24.
3. Let Gradle sync and download dependencies. The wrapper specifies Gradle 9.6.0 and the daemon JVM criteria specify Java 25. Android Studio's bundled JDK was used during development.
4. Start an API 24+ emulator or connect an Android device with USB debugging enabled. Development used a Pixel 6 API 36 emulator.
5. Select the app configuration and press Run.

local.properties is machine-specific and should be regenerated by Android Studio. Do not commit SDK paths, build outputs or credentials. An internet connection may be required for the initial dependency downloads; the app features operate offline.

## Demonstrate strict matching
1. Add Bananas: 1 piece and Milk: 250 ml.
2. Open Suggested recipes. Banana milk smoothie should appear.
3. Open its details to inspect all required ingredients and the method.
4. Change milk to 200 ml. The smoothie should disappear.
5. Change milk to 0.25 l. It should reappear.
6. Delete the banana. It should disappear again.

## Matching boundaries
Names are trimmed and matched without case; explicit aliases cover common plurals. Distinct ingredients such as rice and cooked rice are deliberately separate. No ingredient, seasoning or water is assumed available. Quantities from multiple compatible pantry entries are combined. Mass is not converted to volume or piece counts. Volume conventions: cup = 250 ml, tablespoon = 15 ml, teaspoon = 5 ml. No arbitrary ingredient substitutions are inferred.

Recipes are alternatives, not a meal plan: each is checked independently against the pantry. Viewing a recipe does not consume inventory. Expiry dates organise items; they do not certify food safety or automatically exclude stock.
